# Practical 04 - Interfaces

## Table of Contents

| Practical | Title | Concept |
|---|---|---|
| 27 | Basic Interface Implementation | An interface defines a contract of method signatures a class agrees to implement. |
| 28 | Multiple Interface Implementation | A class can implement several interfaces, achieving a form of multiple inheritance of type. |
| 29 | Default and Static Methods in Interfaces | Since Java 8, interfaces can have `default` methods (with a body, overridable) and `static` utility methods. |
| 30 | Interfaces as Callback Types (Functional Interfaces) | A functional interface has exactly one abstract method, allowing lambda expressions as implementations. |
| 31 | Interface Constants | Fields declared in an interface are implicitly `public static final` (constants). |
| 32 | Marker Interfaces | A marker interface has no methods; it signals metadata about a class (e.g., `Serializable`, `Cloneable`). |
| 33 | Interface-Based Strategy Pattern | Interfaces enable the Strategy pattern — swapping algorithm implementations at runtime behind a common contract. |
| 34 | Comparable and Comparator Interfaces | `Comparable<T>` defines a class's "natural ordering"; `Comparator<T>` defines external, pluggable orderings. |
