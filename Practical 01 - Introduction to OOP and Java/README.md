# Practical 01 - Introduction to OOP and Java

## Table of Contents

| Practical | Title | Concept |
|---|---|---|
| 1 | Hello World and Compilation Basics | Every Java program needs a class with a `main` method as its entry point. `javac` compiles `.java` to `.class` bytecode; `java` runs it on the JVM. |
| 2 | Variables, Data Types and Type Casting | Java is statically typed; primitives (`int`, `double`, `char`, `boolean`, etc.) and casting (implicit widening vs explicit narrowing) are core basics. |
| 3 | Operators and Expressions | Arithmetic, relational, logical, and the ternary operator control expression evaluation. |
| 4 | Control Flow — if/else and switch | Decision-making constructs direct program flow based on conditions. |
| 5 | Loops — for, while, do-while | Loops repeat a block of code; choice depends on whether the iteration count is known in advance. |
| 6 | Arrays — 1D and 2D | Arrays store fixed-size, indexed collections of same-typed elements. |
| 7 | Methods, Parameters and Overloading | Methods encapsulate reusable logic; overloading allows same method name with different parameter lists. |
| 8 | Introduction to Classes and Objects | A class is a blueprint; an object is an instance holding state (fields) and behaviour (methods). |
